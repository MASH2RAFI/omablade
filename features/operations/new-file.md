# Create a file

Create a file in the current or specified folder. The new entry appears in the watched tree. In Files, press `a` or `Ctrl+N`, or right-click a row or the empty space below the rows and choose New file.

```sh
omablade new-file new-note.txt /path/to/project --wait
```

Demonstration: A new regular file appears on disk and in Files.
