# Connect to network servers

Network Storage lists connected shares, every server on the local network or tailnet that shares something, and servers used before, like the Network page of GNOME Files. Connect to Server mounts an address and remembers it.

```sh
omablade blade set right notes,networkstorage
```

Demonstration: A typed smb:// address connects, appears under Connected with an eject button, and returns under Previous Servers after ejecting.
