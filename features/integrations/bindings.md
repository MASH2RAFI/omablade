# Install blade keybindings

Opt into the native bindings role to install Omablade's Hyprland include. Super+Shift+F opens, closes and refocuses the left blade; Super+Shift+N controls the right.

```sh
omablade native roles enable --role bindings
omablade native roles status --json
```

Demonstration: Actual Super+Shift+F input opens, closes and reopens the installed native blade.

Recorded in a separate local compositor using a virtual keyboard. The user's active desktop was not modified.
