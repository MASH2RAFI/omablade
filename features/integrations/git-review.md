# Review changed files with Hunk

Use Review for a selected Git path with changes. Omablade launches Hunk with the selected change context.

```sh
omablade drop-run review /path/to/project/README.md --at 1200,220
```

Demonstration: Hunk opens the sample repository's changed file.

Hunk must be installed. The recording uses a disposable repository.
