# Customize tree keybindings

Customize action bindings in Omablade's keybindings document, then reload it. Binding names describe actions such as search.

```sh
omablade native ipc -- mash2rafi.omablade.control reloadKeybindings
```

Demonstration: A temporary F6 binding focuses search and enters a query.

The demonstration changes only the capture profile's keymap.
